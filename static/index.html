How it works

The AI reads. The rules score. The agent decides.

1

The AI reads

An open AI model hosted on Groq (GPT-OSS 120B by default) reads the message at temperature 0 and returns structured facts: intent, timeline, budget, location, financing, motivation and red flags. The output is cleaned, type checked and retried once if the JSON is broken.

2

The rules score

Plain Python rules turn those facts into a 0 to 100 score. The AI never picks the score, so the same facts always give the same number and every point is explained.

3

The agent decides

You get a recommended next step and a drafted SMS matched to the tier. LeadScout only drafts. You review and send it yourself.

Classification

  • Hot70 and above. Call today.
  • Warm40 to 69. Ask the most useful missing question.
  • ColdBelow 40. Share listings, no pressure.

Offline fallback

If no API key is set or the AI service is unavailable, LeadScout switches to offline pattern rules for extraction and template replies. Scoring stays exactly the same. Every result shows which engine handled it, so you always know.
